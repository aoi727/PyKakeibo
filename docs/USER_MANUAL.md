# My家計簿 操作説明書

作成日: 2026-05-15

## 1. 起動方法

PowerShellでプロジェクトフォルダを開き、次のコマンドを実行します。

```powershell
.\.venv\Scripts\python.exe .\main.py
```

依存関係を入れていない場合は、先に次を実行します。

```powershell
.\.venv\Scripts\python.exe -m pip install -r .\requirements.txt
```

## 2. 画面構成

画面上部には対象月の切替ボタンがあります。

- `今月`: 対象月を今月へ戻します。
- `前月`: 対象月を1か月戻します。
- `翌月`: 対象月を1か月進めます。

画面左側には取引入力、元帳、試算表、各種管理タブがあります。画面左下には対象月の取引履歴があります。画面右側には口座残高と支出内訳があります。

左右の境界、左上と左下の境界はドラッグして幅や高さを変更できます。

## 3. 支出を登録する

1. `支出` タブを開きます。
2. 日付、支出元口座、カテゴリ、メモ、金額を入力します。
3. `＋ 支出を追加` を押します。

日付が本日から未来へ1か月以上、または過去へ半年以上離れている場合は確認ダイアログが表示されます。日付が正しければ `はい` を選択します。

## 4. 収入を登録する

1. `収入` タブを開きます。
2. 日付、入金先口座、カテゴリ、メモ、金額を入力します。
3. `＋ 収入を追加` を押します。

## 5. 資金移動を登録する

1. `資金移動` タブを開きます。
2. 日付、移動元、移動先、メモ、金額を入力します。
3. `⇄ 移動を記録` を押します。

移動元と移動先に同じ口座は選択できません。

## 6. 取引を編集する

1. 左下の取引履歴で編集したい取引を選択します。
2. `選択取引を編集` を押します。
3. 該当する支出、収入、資金移動タブへ内容が読み込まれます。
4. 内容を修正します。
5. `更新の確定` を押します。

編集中は新規登録ボタンが押せません。編集をやめる場合は `編集取りやめ` を押します。

## 7. 取引を削除する

1. 左下の取引履歴で削除したい取引を選択します。
2. `選択行を削除` を押します。

## 8. 口座を管理する

`口座管理` タブで操作します。

### 8.1 口座を追加する

1. 種別、口座名、開始残高を入力します。
2. `＋ 口座を追加` を押します。

### 8.2 口座を編集する

1. 口座一覧で編集したい口座を選択します。
2. 口座名、種別、開始残高を変更します。
3. `選択口座を更新` を押します。

### 8.3 口座を非表示にする

1. 口座一覧で対象口座を選択します。
2. `表示/非表示` を押します。

非表示にした口座は通常の残高表示や新規入力の選択肢から外れます。過去取引や元帳では参照できます。

### 8.4 口座を削除する

1. 口座一覧で削除したい口座を選択します。
2. `未使用口座を削除` を押します。

取引で使われている口座は削除できません。不要な場合は非表示にしてください。

## 9. カテゴリを管理する

`カテゴリ管理` タブで、支出・収入カテゴリを追加または編集できます。

### 9.1 カテゴリを追加する

1. 種別を選びます。
2. カテゴリ名を入力します。
3. `＋ カテゴリを追加` を押します。

### 9.2 カテゴリ名を変更する

1. カテゴリ一覧で変更したいカテゴリを選択します。
2. カテゴリ名を変更します。
3. `選択カテゴリを更新` を押します。

カテゴリ名を変更すると、同じ種別の既存取引も新しいカテゴリ名へ更新されます。

## 10. 摘要辞書を使う

`摘要辞書` タブで、よく使う摘要を登録できます。

1. 摘要を入力します。
2. 用途を選びます。
3. `＋ 摘要を登録` を押します。

支出、収入、資金移動の入力欄では、用途に合う摘要を選べます。入力中の摘要は各タブの `辞書へ保存` からも登録できます。

## 11. 口座元帳を見る

1. `口座元帳` タブを開きます。
2. 口座を選びます。

対象月の取引と残高推移が表示されます。先頭行には前月繰越が表示されます。

PDFに保存する場合は `PDF保存` を押します。

## 12. カテゴリ元帳を見る

1. `カテゴリ元帳` タブを開きます。
2. 種別を選びます。
3. カテゴリを選びます。

対象年の1月1日から対象月末までの取引と累計が表示されます。

PDFに保存する場合は `PDF保存` を押します。

## 13. 試算表を見る

`試算表` タブを開くと、対象月の資産、負債、収益、費用の集計が表示されます。

PDFに保存する場合は `PDF保存` を押します。

## 14. 口座残高の表示を切り替える

画面右側の `口座残高` のトグルスイッチで、口座別残高の表示・非表示を切り替えます。

## 15. データの保存場所

データはプロジェクトフォルダ内の `kakeibo.db` に保存されます。バックアップしたい場合は、アプリを終了してから `kakeibo.db` をコピーしてください。
