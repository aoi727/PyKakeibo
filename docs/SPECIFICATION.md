# My家計簿 仕様書

作成日: 2026-05-15

## 1. 概要

My家計簿は、Python と PySide6 で作成されたローカル実行型の家計簿アプリです。支出、収入、資金移動をSQLiteへ保存し、口座別残高、月次集計、元帳、カテゴリ別元帳、試算表、PDF出力を提供します。

## 2. 実行環境

- 言語: Python
- GUI: PySide6
- DB: SQLite
- 保存ファイル: `kakeibo.db`
- 起動ファイル: `main.py`

## 3. ファイル構成

- `main.py`
  - PySide6 の画面、操作イベント、PDF出力、アプリ起動を担当します。
- `store.py`
  - SQLiteスキーマ、データ登録・更新・削除、集計、元帳データ作成を担当します。
- `models.py`
  - 口座種別、カテゴリ初期値、表示色、dataclassを定義します。

## 4. データベース仕様

### 4.1 accounts

口座マスタです。

| カラム | 内容 |
| --- | --- |
| `id` | 口座ID |
| `name` | 口座名。一意 |
| `account_type` | 口座種別 |
| `opening_balance` | 開始残高 |
| `is_active` | 表示対象なら1、非表示なら0 |
| `sort_order` | 表示順 |
| `created_at` | 作成日時 |

口座種別は `cash`, `bank`, `deposit`, `pay`, `credit_card` です。

### 4.2 transactions

取引データです。

| カラム | 内容 |
| --- | --- |
| `id` | 取引ID |
| `occurred_on` | 取引日 |
| `transaction_type` | `expense`, `income`, `transfer` |
| `category` | 支出・収入カテゴリ |
| `from_account_id` | 出金元口座ID |
| `to_account_id` | 入金先口座ID |
| `memo` | 摘要 |
| `amount` | 金額。1円以上 |
| `created_at` | 作成日時 |

支出は `from_account_id`、収入は `to_account_id`、資金移動は両方を使用します。

### 4.3 memo_templates

摘要辞書です。

| カラム | 内容 |
| --- | --- |
| `id` | 摘要ID |
| `memo` | 摘要文字列。一意 |
| `usage_type` | `common`, `expense`, `income`, `transfer` |
| `created_at` | 作成日時 |

### 4.4 categories

支出・収入カテゴリマスタです。

| カラム | 内容 |
| --- | --- |
| `id` | カテゴリID |
| `transaction_type` | `expense` または `income` |
| `name` | カテゴリ名 |
| `sort_order` | 表示順 |
| `created_at` | 作成日時 |

同じ種別内で同名カテゴリは登録できません。

## 5. 主な機能

### 5.1 月次表示

画面上部で対象月を切り替えます。取引履歴、月次支出、月次収入、支出内訳、試算表は対象月を基準に表示します。

### 5.2 取引登録

支出、収入、資金移動を登録できます。登録時に、日付が本日から未来へ1か月以上、または過去へ半年以上離れている場合は確認ダイアログを表示します。

### 5.3 取引編集

取引履歴または口座元帳で取引を選択し、該当タブへ読み込んで編集できます。編集中は新規登録ボタンを無効化し、更新確定または編集取りやめで編集状態を解除します。口座元帳から編集した場合は、更新確定または編集取りやめで元の口座元帳へ戻ります。

### 5.4 取引コピー

取引履歴、取引検索、口座元帳、カテゴリ元帳で選択した取引を新規登録用にコピーできます。コピーした取引は該当する支出、収入、資金移動タブへ読み込み、日付や金額などを変更して登録できます。取引検索、口座元帳、カテゴリ元帳からコピーした場合は、登録またはキャンセル後に元のタブへ戻ります。

### 5.5 取引削除

取引履歴または口座元帳で選択した取引を削除できます。

### 5.6 取引検索

金額、摘要、カテゴリ、口座名、日付、取引種類を対象に取引を検索できます。検索期間は、全記録期間、または選択中の対象月が属する本年度から選択できます。本年度は4月1日から翌年3月31日までです。金額検索はカンマ、円記号、全角数字を正規化して検索します。

### 5.7 口座管理

口座の追加、名称編集、種別変更、開始残高編集、表示・非表示切替、表示順変更、未使用口座削除に対応します。取引で使用済みの口座は削除できません。

### 5.8 カテゴリ管理

支出・収入カテゴリの追加、名称変更、表示順変更、未使用カテゴリ削除に対応します。カテゴリ名を変更した場合、同じ種別の既存取引カテゴリも追随更新します。カテゴリ種別の変更は不可です。

### 5.9 摘要辞書

よく使う摘要を登録できます。用途は共通、支出、収入、資金移動から選択します。

### 5.10 口座元帳

選択した口座について、対象月の取引と残高推移を表示します。開始行には前月繰越残高を表示します。口座元帳から取引を追加する場合は、選択中の対象月と口座を初期値にします。保存またはキャンセル後は元の口座元帳へ戻ります。

### 5.11 カテゴリ元帳

支出または収入のカテゴリを選択し、対象年の1月1日から対象月末までの取引と累計を表示します。カテゴリ元帳から取引を追加する場合は、選択中の対象月とカテゴリを初期値にします。取引の変更、コピー、削除にも対応し、保存またはキャンセル後は元のカテゴリ元帳へ戻ります。

### 5.12 試算表

対象月の資産、負債、収益、費用を集計し、借方・貸方形式で表示します。

### 5.13 PDF出力

口座元帳、カテゴリ元帳、試算表をPDF保存できます。

## 6. 表示仕様

- 画面左側は取引入力・管理タブと取引履歴で構成します。
- 画面右側は口座残高と支出内訳を表示します。
- 左右ペイン、左上フォーム領域と左下取引履歴、右側の口座残高と支出内訳はスプリッターで幅・高さを変更できます。
- ウィンドウサイズと各スプリッターの状態は次回起動時に復元します。ただし、表示先画面に保存済みウィンドウサイズが収まらない場合は復元しません。

## 7. 制約事項

- データはローカルの `kakeibo.db` に保存します。
- 同一種別内で同名カテゴリは登録できません。
- 摘要辞書の同一摘要は重複登録できません。
- 取引で使用済みの口座は削除できません。
- カテゴリ種別は変更できません。
