# 家計管理

Python + PySide6 で作る、SQLite保存のローカル家計簿アプリです。
支出、収入、資金移動を記録し、口座別残高、取引検索、元帳、試算表、PDF出力を扱えます。

## 起動

```powershell
.\.venv\Scripts\python.exe .\main.py
```

## 依存関係

```powershell
.\.venv\Scripts\python.exe -m pip install -r .\requirements.txt
```

## 主な機能

- 支出、収入、資金移動の登録・編集・削除
- 既存取引のコピー登録
- 金額、摘要、カテゴリ、口座名、日付、取引種類による取引検索
- 本年度または全記録期間を対象にした検索
- 現金、普通預金、定期預金等、Pay支払、クレジットカードの口座管理
- 口座の表示/非表示、表示順変更、未使用口座削除
- 支出・収入カテゴリの追加、名称変更、表示順変更、未使用カテゴリ削除
- 摘要辞書による入力補助
- 口座元帳、カテゴリ元帳、試算表の表示
- 口座元帳とカテゴリ元帳からの取引追加・変更・コピー・削除
- 月次支出、月次収入、カテゴリ別支出内訳、総資産の表示
- 口座元帳、カテゴリ元帳、試算表のPDF保存
- ウィンドウサイズとペイン幅・高さの保存、次回起動時の復元
- SQLite (`kakeibo.db`) への自動保存

## データ

データベースはプロジェクトフォルダ内の `kakeibo.db` に保存されます。
バックアップする場合は、アプリを終了してから `kakeibo.db` をコピーしてください。
